# 캐릭터 이미지 형식과 부팅 힌트 (2026-08-28)

심층 검토 P1-16·P1-17. 둘 다 "재는 것부터" 했고, 잰 값이 고칠 방향을 정했다.

## 1. 캐릭터는 WebP 파생본으로 받는다 (P1-16)

### 잰 값

| 항목 | 값 |
|---|---|
| count 모드 진입 시 이미지 | **947KB** (ten.png 473KB + five.png 473KB) |
| 원본 해상도 | 1024×1536 |
| 화면 최대 표시 폭 | 570px (빼기 화면) |
| 최소 표시 폭 | 99px (곱하기 친구) |

### 왜 해상도는 그대로 두는가

표시 폭이 570px이어도 **고해상도 화면(DPR 2)은 1140px를 원한다.** 원본이
1024px이니 이미 빠듯하다 — 줄이면 그 화면에서 흐려진다. 줄일 것은 용량뿐이다.

### 무엇을 했나

원본 PNG는 **한 장도 건드리지 않고** 같은 해상도의 WebP를
`assets/characters/webp/` 에 파생본으로 쌓았다(`scripts/generate_character_webp.py`,
q92). `<img>` 는 `src` 에 PNG, `srcset` 에 WebP를 건다 — 홈 카드가 이미 쓰는
방식과 같다. SVG `<image>` 는 srcset이 없어 파생본을 바로 가리킨다.

q92 근거: 표시 크기(570px)로 줄여 비교했을 때 **RMS 오차 0.94/255**, 8단계
넘게 차이 나는 서브픽셀 0.18%, 알파는 완전 보존. 육안으로 구분되지 않는다.

| | 예전 | 지금 |
|---|---|---|
| count 진입 이미지 | 947KB | **81KB** |
| add 진입 이미지 | 100KB | 33KB |
| 캐릭터 자산 전체 | 16MB(PNG) | +3.6MB(WebP 파생본) |

### 가드

`tests/character-image.test.mjs` — 모든 원본에 파생본이 있는지, 파생본이 원본의
1/4보다 작은지, 그리고 **캐릭터 주소를 `character-image.mjs` 밖에서 만들지
않는지**. 마지막 것이 핵심이다: 새 화면이 경로를 직접 이어 붙이면 그 화면만
조용히 원본을 받는다.

## 2. 모듈 힌트로 부팅 워터폴을 편다 (P1-17)

### 잰 값 (라이브, GitHub Pages, h2)

```
TTFB 284ms · domInteractive 298ms · DCL 1231ms
마지막 모듈: 974ms에 시작해 1176ms에 도착
```

스크립트는 gzip 302KB — **바이트는 병목이 아니었다.** 병목은 그래프 깊이다.
`<script type="module" src="app.mjs">` 하나만 걸려 있으니 브라우저는 부모를
파싱해야 자식을 발견한다. 깊이가 4단이라 왕복이 네 번 쌓였다.

### 무엇을 했나

`index.html` `<head>` 에 그래프 전체(57개)를 `<link rel="modulepreload">` 로
걸었다. 코드는 한 줄도 바뀌지 않는다. 목록은
`node scripts/sync_modulepreload.mjs` 가 실제 import 그래프에서 생성한다.

로컬 A/B(왕복 100ms): 마지막 모듈 시작 **1663ms → 116ms**. 로컬 서버는
HTTP/1.1이라 동시 6개 제한에 걸려 DCL 단축은 5~10%에 그쳤다 — 라이브(h2)에서
다시 잰다.

### 왜 동적 import 로 쪼개지 않았나

바이트가 병목이 아니었다. 모드별 지연 로딩은 119KB짜리 `app.mjs` 의 시작 함수
전부를 async로 바꿔야 하는데, 얻는 것(302KB 중 일부)이 병목이 아닌 축이다.
힌트는 코드를 안 바꾸고 병목인 축을 바로 친다.

### 가드

`tests/modulepreload.test.mjs` — 목록이 import 그래프와 정확히 같은지, head
안에 있는지, 걸어 둔 파일이 실제로 있는지. 모듈을 새로 만들고 힌트를
빠뜨리면 그 모듈만 다시 늦게 출발하는데 아무도 눈치채지 못하기 때문이다.

`sync_modulepreload.mjs` 자체도 한 번 조용히 실패했다(마커의 괄호·점이
정규식 특수문자였다). 못 고쳤는데 "반영했다"고 출력했다 — 지금은 쓰기 전에
결과를 확인하고, 어긋나면 실패로 끝낸다.
