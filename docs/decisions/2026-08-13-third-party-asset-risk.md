# 제3자 자산 재배포 리스크 — 인지하고 현행 유지 (2026-08-13)

세 모델(fable·gemini·kiro) 보안 감사에서 나왔고, 대장이 **"지금은 그대로 두고 기록만"**
으로 판단했다. 다음 사람이 같은 발견을 다시 들고 오지 않도록 여기 남긴다.

저장소 어디에도 출처·허락·라이선스 표기가 없고 LICENSE 파일도 없다.

## 결정

**현행 유지.** 가족 한 명이 쓰는 소규모 교육용 사이트이고, 실제 집행이 오는 경우
대응 비용보다 지금 손대는 비용(6번 게임 안내방송 상실, 캐릭터 161장 재제작,
공개 URL 상실)이 크다고 판단했다.

## 다시 꺼내야 할 때

- 저장소나 사이트를 **홍보·공유**하기 시작할 때 (사적 이용 논거가 약해진다)
- 권리자에게서 연락이 올 때
- 저장소를 조직 계정이나 회사 인프라로 옮길 때

## 그때의 선택지 (검토 완료, 실행 안 함)

1. **저장소·Pages 비공개 전환** — 가장 확실하지만 무료 플랜에서는 Pages가 막혀
   아이가 쓰던 공개 URL이 사라진다.
2. **안내방송 mp3만 저장소에서 제외** — 가장 명확한 IP만 끊는다. 게임은 음성이 없는
   역에서 자막으로 넘어가는 폴백이 이미 있어 동작은 유지된다(`README.md` 소리와 음성 절).
3. **캐릭터·명칭 오리지널 교체** — 근본 해결이지만 161장 재제작 + 저장소명·문구 전면 교체.

## 함께 나온 것 — 커밋 이메일

공개 커밋 히스토리 432건 중 **417건의 author가 회사 도메인**이다
(`git log --all --format=%ae | sort | uniq -c`). 게임 화면에는 노출되지 않고 git 메타데이터에만
있다. 앞으로만 막으려면 이 저장소에 `git config --local user.email <noreply>` 한 줄,
과거까지 지우려면 417커밋 재작성 + force-push가 필요하다. **아직 결정되지 않았다.**
